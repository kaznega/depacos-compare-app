# アフィリエイト行き先対応表（整備中）

方針は affiliate-design.md が正本。ここは「どの商品をどこへ飛ばすか」の作業台帳。
行き先は実際に商品ページを確認してから書くこと（推測でURLを作らない）。

## 行き先の決め方（商品＝ライン単位）
1. ISETAN BEAUTY online にその商品のページがある → 主リンク候補（提携後にID付き化）。
2. 無ければ Amazon 公式ブランドストア / 楽天市場 公式ショップの商品ページ。
3. それも無ければ Yahoo!ショッピングの公式ストア商品ページ。
4. どこにも無ければ主リンクなし（公式ページを副リンク `official` にだけ入れる）。
- モールは公式ストア・正規販売店のみ。並行輸入・非正規は不可。
