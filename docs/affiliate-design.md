# 商品画像・アフィリエイトリンク設計メモ（2026-10-30 土台実装／2026-11-01 収益方針を確定）

## 目的
アプリの最終目標は収益化。各商品に「商品画像」と「購入先リンク」を付け、A/Bテストで色を決めたユーザーをそのまま購買へつなげる。データがある商品だけ表示され、無い商品は従来表示のまま。

## 飛ばし先の方針（2026-11-01 ユーザー承認・確定）
前提の訂正: ブランド公式EC（Dior・SUQQU等）には個人向けアフィリエイトがほぼ存在しない。公式リンクは無報酬であり、収益の主軸にはならない。

### 主リンク（購買ボタン）= アフィリエイトが付く行き先のみ。優先順位
1. **ISETAN BEAUTY online（三越伊勢丹・旧meeco）** — デパコス約180ブランドを扱う正規の百貨店EC。アフィリエイトは楽天リンクシェア限定、通常報酬1%（増額キャンペーン時3〜5%）。デパコス横断の主軸。
2. **Amazon 公式ブランドストア / 楽天市場の公式ショップ** — 商品ごとに有無あり。楽天市場はリンクシェアからも提携可能。
3. **Yahoo!ショッピング** — バリューコマース経由。公式ストアがあるブランドの受け皿。

### 副リンク = ブランド公式の商品ページ
色番・色味の最終確認用。無報酬でも併記する価値があるものだけ付ける（スキーマは下記 `official`）。

### 運用ルール（絶対）
- モール（Amazon／楽天／Yahoo）内では、**公式ストア・正規販売店の商品ページにだけ**飛ばす。並行輸入・非正規の出品者には飛ばさない（色と正規品の正確さ＝アプリの信用を守る）。
- 飛ばし先は原則「その商品のページ」。トップページや検索結果には飛ばさない。
- リンクの近くに「広告」表記を出す（ステマ規制対応）。
- 料率は低い前提（1〜数%）。全商品にリンクを付け、決定直後の導線（#8「この色を探す」の差し替え先、#18 決定カード）で件数を積む。

### 進め方
1. ユーザー: 楽天リンクシェアに登録 → ISETAN BEAUTY online へ提携申請（本人手続き）。
2. アシスタント: 提携待ちの間に「どの商品をどこへ飛ばすか」の対応表（affiliate-destinations.md）を正本側で整備する。
3. 提携が通った先から、`buy.url` をID付きリンクへ差し替えて有効化する（差し替えだけで有効化できる設計）。

## データ形式（正本 master-catalog.json とアプリ CATALOG で共通）
ライン単位が基本。色（shade）単位の値があればそちらが優先される。

```jsonc
{
  "brand": "SUQQU",
  "line": "スック ベルベット フィット リップスティック",
  "type": "lip",
  "img": "https://…",                    // 任意：商品画像URL（外部読み込み前提・アプリに同梱しない）
  "buy": { "url": "https://…", "kind": "ISETAN BEAUTY" },  // 任意：主リンク（収益）。kind は行き先表示名（ISETAN BEAUTY／Amazon／楽天／Yahoo! 等）
  "official": "https://…",               // 任意：公式商品ページ（副リンク・色番確認用）
  "shades": [
    { "name": "12 想秘 -OMOIHIME", "color": "#cc8470",
      "img": "https://…",                 // 任意：色単位で上書き可
      "buy": { "url": "https://…", "kind": "Amazon" } }
  ]
}
```

## アプリ側の挙動（土台実装済み・2026-10-30）
- 展開時に shade へ伝播：`img: shade.img || line.img || ''`、`buy: shade.buy || line.buy || null`。
- 表示場所：試着ステージの A／B 調整パネル（選択中の色の情報欄）。
  - `img` がある場合のみ商品画像スロット（46×46）を表示。読み込み失敗（onerror）時は自動で隠れ、従来の色チップ表示にフォールバックする。
  - `buy` がある場合のみ「購入先を見る（種別）」ボタンを表示し、`target=_blank rel="noopener noreferrer"` で開く。
- データが無い商品では画像・ボタンとも一切出ない。
- ※ `official` 副リンクの表示は今後の拡張（未実装）。#8「この色を探す」は、buy がある色では購入リンクへ差し替える想定。

## テスト投入（1件・検証用）
- SUQQU ベルベット フィット リップスティック（ライン単位）：
  - buy: 公式商品ページ https://www.suqqu.com/ja/categories/colorMakeup/lip/p/PAC_S01146 （kind: 公式、アフィリエイトIDなしの通常リンク）※新方針では、これは `official` 側に移し、buy は収益リンクに差し替える対象。
  - img: 同ページの公式商品画像URL（suqqu.com/medias の PAC-S01146-VFL06-best.jpg）

## 後からリンクを足すときの入れ方
1. affiliate-destinations.md の対応表で行き先を確認する。
2. master-catalog.json の該当ライン（または色）のレコードに `img` / `buy` / `official` を追加する。
3. update-procedure.md の手順でアプリへ反映し、ゲートでボタン表示と遷移を確認する。

## 収益化設計の確定（2026-11-03 ユーザー指示）
- 収益化の核心は「気に入ったコスメを、その場で Amazon・Yahoo!ショッピング・楽天市場・Qoo10 で買える」こと。収益化はユーザー体験向上の延長線として設計する（押し付けない）。
- 色比較の最初のページ（A/B体験の入り口）では商品ページへ飛ばさない。比較体験は今までどおり体験専用に保つ。
- 代わりに、気に入ったタイミング（決定カード／買いたいリスト／色の詳細）から開ける「簡易商品詳細ページ」を用意し、そのページに各モールの購入ボタン（Amazon／Yahoo!ショッピング／楽天市場／Qoo10／ISETAN BEAUTY）を設置する。各ボタンにはアフィリエイトリンクを入れ、「広告」表記を付ける。
- ボタンは、その商品についてそのモールのリンクが実在するものだけ表示する。リンク付けは従来どおり完全一致（ライン＋色番＋色名）ルールを全モールに適用し、モール内は公式ストア・正規販売店のみ。
- 未登録のプログラム：Amazonアソシエイト／楽天市場（LinkShare経由の申請未提出）／Yahoo!ショッピング（バリューコマース）／Qoo10アフィリエイト。登録はユーザーのアカウント手続きが必要なものがあるため、手順を案内しながら進める。
- 進め方：まず詳細ページの受け皿をアプリに実装（ISETANボタンで開始）→ 登録が済んだモールから順にボタンとリンクを追加（人気ライン優先）。
