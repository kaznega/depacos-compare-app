# デパコス比較アプリ

デパコス（百貨店コスメ）の色を、自分の顔写真の上で2色同時に試して比べられるWebアプリの引き継ぎ用リポジトリ。

- アプリ本体: `index.html`（単一ファイル、ビルド `2026-11-04-ux28`）
- 仕様書: `SPEC.md`（概要・データ仕様・絶対ルール・申し送り）
- 色カタログ正本: `data/master-catalog.json`（8,456色 / 41ブランド、購入リンク実効4,697色）
- 運用資料: `docs/`（収益化設計・行き先台帳・更新手順・ウォッチリスト・改善提案ログ）
- 公開リンク: https://muse.ai/s/space-4-xzx06tokolzxwn/Zax88qN4vh6crIIMZ2Sq4d3l2AlNksTWXu8aEGcf6jg

作業を引き継ぐ場合は、まず `SPEC.md` の「絶対ルール」（色データ／顔検出／リンク付け／検証）を確認すること。
